# Generated Outputs

This directory is reserved for local generated runs and is ignored by Git.

Do not commit continuation ladders, raw Newton diagnostics, checkpoint trees,
or per-run figures/tables here. Promote only decisive compact evidence into
`results/canonical/` with configuration, provenance, scientific status, and
SHA-256 checksums.

The complete pre-cleanup output tree is recoverable from tag
`pre-cleanup-p0-2026-07-11` and the verified archive recorded in
`docs/manifests/archive_verification.json`.
