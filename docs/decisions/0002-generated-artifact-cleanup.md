# Decision 0002: Generated Artifact Cleanup

Status: accepted, 2026-07-11.

Bulk checkpoints, raw tables, exploratory figures, superseded reports, and
full-paper PDFs leave the default branch only after immutable tagging, complete
inventory, external archive creation, fresh extraction/hash verification, and
canonical replacement.

Git history is not rewritten in this work package. The pre-cleanup tag and
external archive remain the recovery mechanisms.
