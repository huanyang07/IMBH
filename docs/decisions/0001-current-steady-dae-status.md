# Decision 0001: Status of the Current Steady Phase-DAE Model

Status: accepted, 2026-07-11.

The current positive phase branch is retained as a legacy mathematical and
numerical benchmark. It is not labeled a certified physical mass-loaded-wind
branch because the model-validity boundary precedes the formal endpoint and the
physical angular-momentum closure is unresolved.

Further `eta_E` continuation is paused. The next physics change must introduce
explicit stream/wind angular transport and unified conservative flux equations.
