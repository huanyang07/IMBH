# Bounded AP coarse-trajectory manifest

This package freezes a two-anchor, eleven-field, exponentially integrated AP trajectory test at primary and held-out physical states. It binds matched refinement, source-nullity preservation, stiff fast-manifold slaving, bitwise arbitrary-step restart, zero online truth calls, and a measured 100,000-step cost projection.

The test is local and linearized. It does not supply a cycle-wide physical coefficient atlas and does not authorize complete-cycle execution.
